# Deluxe Clock XL — mises à jour

Ce dépôt public ne contient que les **mises à jour du firmware** de la Deluxe Clock XL (gamme Lattice), publiées dans les *Releases*.

- Chaque version est **chiffrée** (AES-256) et **signée** (ECDSA P-256) : seule une Deluxe Clock XL peut la déchiffrer et l'installer.
- L'horloge vérifie elle-même les nouvelles versions une fois par jour. On peut aussi lancer la vérification depuis son configurateur (`http://deluxe-clock.local/`, section Système → Mises à jour).

Le code source est privé.
